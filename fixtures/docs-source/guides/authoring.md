# Authoring guide

## Embedded code examples

Markdown in a MiKode repository is formatted by
`@mikode13/code-style`, the same shared export the Source capability resolves. Embedded
code blocks are indented with tabs and use single-quoted strings because that is what the
shared configuration produces, not because this document chose it.

```ts
const capabilities = ['source', 'documentation'];
```
